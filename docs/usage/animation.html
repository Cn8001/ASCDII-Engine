Animation

Every property that the Inspector edits can be animated. Clips are sampled from scene time, so scrubbing is exact and playback does not drift. Animator controllers switch between clips as states.

Concepts

  • A clip belongs to an object and has a name and a play mode: once, loop or pingpong. An object can have several clips.
  • A track animates one property, such as pos.z, blob.color or light.intensity. Numbers, vectors and colors are interpolated; true or false values change at the key.
  • A key is a value at a time, with an ease toward the next key: linear, in, out, inout, step, back or elastic.

Recording a clip

  1. Select a lantern and open the Animation tab (Ctrl+6).
  2. Press REC. While it is red, every change made in the Inspector is recorded as a key at the playhead.
  3. Click the ruler at 0 to move the playhead there and set pos z to 0. A clip is created with its first key.
  4. Click the ruler at 1.5 and set pos z to 2.
  5. Press REC again to stop recording and the play button in the Animation tab to preview. Set the clip to pingpong to move up and down continuously.
  6. Click a key to select it and choose an ease, for example inout. Dragging keys sideways retimes them in steps of 0.05 seconds. The trash button deletes the selected key.
Without RECThe diamond at the end of a property row in the Inspector records a key for that property only. A double click on a track lane adds a key at that time.

Floating window

The float button at the right of the Animation header detaches the panel into a window that can be moved and resized; its position is remembered. The arrow in its title bar docks it again.

Several clips per object

+ Clip in the Animation tab adds another clip to the selection, for example walk next to idle. A click on a clip's header makes it the clip that receives new keys; it is highlighted. A double click renames it.

Animator

An Animator component plays its object's clips as the states of a controller asset and switches between states when the conditions of a transition hold.

  1. In the Project window, choose Create, Animator Controller. The controller is created in the open folder and the Animator window opens.
  2. Add parameters on the left: float, bool or trigger. A trigger is true for one transition and then resets.
  3. Add states with + State and select each state's clip and speed on the right. The start state has an amber border; any state can be made the start state.
  4. Shift drag from one state to another to add a transition, and give it conditions such as speed > 0.1, or enable After the clip ends. A transition from any state can leave every state, for example for hits.
  5. Add an Animator component to the object and drag the controller onto its controller slot. The graph button on the card opens the controller.

While the game runs, the selected object's active state is highlighted in the Animator window. An object with an animator plays its clips only as states; the timeline still previews them while editing. Condition operators are >, <, == and !=.

local anim = self:component("animator")
anim:set("speed", 3)
anim:trigger("jump")
log(anim.state)
anim:play("idle")   -- jump to a state

Animation from scripts

Scripts start tweens at run time, for doors, pickups and interface elements. Tweens use the same eases as keys and are not saved in the scene.

self:tween("pos.z", 4, 0.6, "out")   -- property, target, seconds, ease
self:play("bob")                    -- start or stop a clip by name
self:stop("bob")
