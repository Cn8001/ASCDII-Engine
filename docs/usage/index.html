ASCDII Engine

ASCDII Engine is a 2.5D game engine that renders with Unicode Braille characters. Worlds are built in a desktop editor, scripted in Lua, and built into games that run in any terminal with 24 bit color.

Features

AreaContents
RenderingBoxes, cylinders, cones, spheres, planes, terrain with cliffs, models, camera facing sprites, shadows, point, spot and directional lights, fog, water and color grading, resolved per Braille dot. See Rendering.
EditorHierarchy, Scene and Game views with move, rotate and scale tools, Inspector, Project window, Console, Animation timeline, Animator graph, Particle Editor, Package Manager and builds. See The editor.
ObjectsGameObjects with components, parent and child hierarchies, prefabs with overrides, references between objects and assets, and a camera component. See GameObjects and components and Scenes and prefabs.
ScriptingLua scripts with Inspector fields and hooks, access to every object, component, the camera, the environment and the render pipeline, and reloading on save. See Lua scripting.
AnimationClips with keys and easing, and animator controllers with states, parameters and transitions. See Animation.
PhysicsBox, circle and mesh colliders, triggers and rigidbodies, edited in the Scene view. See Physics.
AudioWAV and MP3 sounds played by audio sources and scripts. See Audio.
ParticlesA particle system with nine presets and a Particle Editor. See Particles.
AssetsTextures, materials, OBJ models, sprites and packages, organized in any folder layout. See Assets and import.
BuildsA folder per platform with the player, the compiled game data and checksums, for Windows and Linux. See Build.
