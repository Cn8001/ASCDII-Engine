ASCDII Engine

A 2.5D game engine that draws with Unicode Braille. Build a world with a desktop editor, script it in Lua, and ship it as a single executable that runs in any truecolor terminal.

What you get

  • A real 2.5D renderer. Boxes, towers, roofs, terrain with cliffs, camera facing sprites, shadows, point lights, fog and water, all resolved per Braille dot.
  • An editor that feels familiar. Hierarchy, Scene and Game views, Inspector with components, Project window, Console and an Animation window, in the layout you know from Unity.
  • Lua scripting. Write behaviours in your own code editor. Saving a file reloads it in the running scene.
  • Plain project files. A game is a folder of JSON, Lua and art, made to live in git.
  • One file releases. Build a Windows or Linux executable, or a full release with zips and checksums, in one click.
