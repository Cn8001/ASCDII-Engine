Build

A build is the game, ready to hand out: a folder with the player named after your game, your project compiled into one data file, and a checksum list. Nothing to install for the people who play it.

From the editor

  1. Press Build in the toolbar or Ctrl+B.
  2. Choose the platforms; both are on by default. Set the version if it changed; it is stored in the manifest.
  3. Press Build. Unsaved changes are saved first, so the build always matches the editor.
  4. Press Show to open the output folder.
build/linux/Dragonfall/
  Dragonfall              the player
  data/game.pak           scenes, prefabs, models, sounds, scripts, compiled
  SHA256SUMS
build/windows/Dragonfall/
  Dragonfall.exe
  data/game.pak
  SHA256SUMS

Zip the folder or upload it as it is; that is the release. Single file instead puts everything into one executable per platform, with a .sha256 file next to it.

What goes into game.pak

  • Only what the game needs: the manifest, scenes, prefabs, materials, animator controllers, scripts, sprites, textures, models and sounds. Readmes, notes, .gitignore and the build folder stay out.
  • No .meta files: their ids and import settings are compiled into one index inside the pak.
  • The pak is compressed and encrypted, so a build cannot be browsed or opened as a project in the editor.
How safe is it?The key has to travel with the player, so someone who takes the player apart can still get at the files, as with every engine. The pak keeps a game's files from being copied by anyone who simply opens the folder.

From the command line

# a folder build for this machine, in build/Quest
ascdii build ~/games/quest
# one executable instead
ascdii build ~/games/quest -single
# for another platform, with that platform's player
ascdii build ~/games/quest -player bin/players/ascdii-windows-amd64.exe -out build/Quest-win

Publish on GitHub

cd build/linux && tar czf Quest-0.2.0-linux.tar.gz Quest
git tag v0.2.0 && git push --tags
gh release create v0.2.0 build/linux/Quest-0.2.0-linux.tar.gz --title "Quest 0.2.0"

Running a built game

./Quest/Quest
Quest\Quest.exe
# check the download
cd Quest && sha256sum -c SHA256SUMS
# a still frame without a terminal, for screenshots or CI
./Quest/Quest --preview -size 160x50 -time 2

The player looks for data packed into itself first, then for data/game.pak next to it. Keep the two together when you move a build.

VersionsThe engine is 0.0.1. Empty projects start at 0.0.1, projects from the Dragonfall template at 0.1.0. The manifest also records the engine version the project was last saved with.
