Physics

Colliders give objects a footprint on the ground; a Rigidbody makes an object fall, slide and bounce off them. The model fits a 2.5D world: shapes live on the ground plane, and height is a range above it.

Colliders

ComponentShapeSettings
Box ColliderA rectangle that turns with the object's Z rotation.size (x and y on the ground, z the height), offset, trigger
Circle ColliderA circle.radius, height, offset, trigger
Mesh ColliderThe footprint of the object's model, its outline seen from above.trigger

Select an object to see its colliders outlined in green in the Scene view, triggers in blue. A collider that is not a trigger blocks the player and rigidbodies; objects without colliders still block with their bounds when marked Solid.

Rigidbody

Add a Rigidbody next to a collider and the object moves on its own in play mode.

PropertyDoes
massHeavier bodies push lighter ones further; forces move them less.
gravityFall until the ground or the top of a collider below.
dragHow quickly sliding slows down.
bounce0 stops dead at a wall, 1 bounces back at full speed.
kinematicMoved only by scripts and animation; others still bump into it.
velocityCurrent speed in world units per second; set it to throw things.

Triggers and hooks

A trigger collider reports contacts without pushing, for doors, pickups and zones. Scripts on either object hear about a contact when it begins:

function on_trigger(self, other)
  if other.name == "hero" then
    play_sound("audio/coin.wav")
    self:destroy()
  end
end

function on_collision(self, other)
  log("bumped into", other.name)
end
local rb = self:component("rigidbody")
rb:add_force(vec3(0, 0, 9))   -- a jump: velocity changes by force / mass
rb.velocity = vec3(4, 0, 0)
Keep it simplePhysics is deliberately small: no friction model, no stacking solver, no rotation from impacts. It is enough for crates, balls, pickups and walls; for anything more, move objects from a script.
