Dragonfall module

Dragonfall is the sample game shipped with the engine: a valley with a keep, a river, a sleeping dragon and a knight. It consists of a code module, which adds its components to the engine, a project template and a package.

Using the module

FormUse
TemplateSelecting Dragonfall in New project creates a complete project with the sample scene. On the command line: ascdii new <dir> -template dragonfall.
PackageThe Package Manager installs the sample's assets and the module into an existing project, see Packages. On the command line: ascdii pack install <dir> dragonfall.
ModuleProjects that list "dragonfall" under modules in their manifest can use the components below; the template and the package add the entry. The GameObject menu shows them in a Dragonfall submenu.

The sample scene

ObjectContents
Main CameraThe game camera, at the knight's start position.
terrain, forest, grassThe valley, its trees and its grass, generated from seeds.
bridge, castleThe bridge over the river and the keep.
dragonThe dragon, with a toggle that wakes it on E and the script scripts/dragon.lua, which shows a hint while the knight is near.
heroThe knight, moved by a Player component; the camera follows it.
roadFour instances of the prefabs/lantern.prefab.json prefab: a post, a flame particle system and a light.
crystalA glowing sphere with a light, the animation clip bob and the script scripts/crystal.lua, which shows a message while the knight is near.
hudThe title, area name, time of day, map and key help, with toggles for the map (M) and the help (H).
rulesDay Night on T and Quit Key on Q.

Component reference

Property names are used as described in the engine's Component reference; the kinds below carry the df. prefix.

Terrain df.terrain

The Dragonfall valley: hills, cliffs and a river, generated from a seed. GameObject menu and Add Component.

PropertyTypeDefaultDescription
seedint, 0 to 999992026Varies the landscape.
waterfloat, -3 to 0-0.9Height of the water level.

Forest df.forest

Trees placed over the Dragonfall terrain. GameObject menu and Add Component.

PropertyTypeDefaultDescription
seedint, 0 to 999992026Varies the placement.
densityfloat, 0 to 11Share of possible spots that get a tree.
swayfloat, 0 to 20.35How far the trees move in the wind.

Grass df.grass

Grass blades over the Dragonfall terrain. GameObject menu and Add Component.

PropertyTypeDefaultDescription
seedint, 0 to 999992026Varies the placement.
densityfloat, 0 to 10.85Share of possible spots that get grass.
detailboolfalseDraws more blades near the camera.

Castle df.castle

The Dragonfall keep with towers, walls and a gate. GameObject menu and Add Component.

PropertyTypeDefaultDescription
stonecolor#76787cWall color.
roofcolor#3e5266Roof color.
bannercolor#b0383eBanner color.
torchesbooltrueLights the torches.

Bridge df.bridge

A wooden bridge. GameObject menu and Add Component.

PropertyTypeDefaultDescription
lengthfloat, 1 to 609Length in world units.
widthfloat, 1 to 306Width in world units.
woodcolor#846240Wood color.

Dragon df.dragon

The Dragonfall dragon. GameObject menu and Add Component.

PropertyTypeDefaultDescription
awakeboolfalseWakes the dragon: it flaps and looks around.
firebooltrueBreathes fire while awake.

Hero df.hero

The Dragonfall knight. GameObject menu and Add Component.

PropertyTypeDefaultDescription
walkingboolfalsePlays the walk cycle; set by the player component.
speedfloat, 0.1 to 41Walk cycle speed multiplier.

HUD df.hud

The Dragonfall heads-up display: title, area name, time and a map. GameObject menu and Add Component.

PropertyTypeDefaultDescription
titlestringDRAGONFALLTitle in the top left corner.
showMapboolfalseShows the map.
showHelpboolfalseShows the key help.
seedint, 0 to 999992026Terrain seed the map is drawn from.
