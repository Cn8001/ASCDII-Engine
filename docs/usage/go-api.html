Go API

Everything the editor does is available from Go through one public package, gitlab.com/rapsodoinc/rapsodo-studios/ascii-engine/pkg/ascdii.

The smallest program

package main

import (
  "context"
  "os"

  "gitlab.com/rapsodoinc/rapsodo-studios/ascii-engine/pkg/ascdii"
)

func main() {
  e := ascdii.New(ascdii.Options{})
  s := e.Scene()
  s.Add("ground", ascdii.Ground(40, 40, ascdii.Hex("#46623e")))
  s.Add("crate", ascdii.Box(ascdii.V3(2, 2, 2), ascdii.Hex("#b08050"))).Blocking()
  s.Add("hero", ascdii.Blob(.8, ascdii.Hex("#e8b04b"))).At(0, 5, 0).With(ascdii.Player(), ascdii.Quit("q"))
  s.Animate("crate", ascdii.Tween("pos.z", 0.0, 1.5, 1.2, ascdii.InOut).Bouncing())
  _ = e.Run(context.Background(), os.Stdin, os.Stdout)
}

Load a project folder instead of building the scene in code:

e, err := ascdii.OpenDir(ctx, "~/games/quest", ascdii.Options{})

Your own node kind

A node exposes its properties through a binder, draws in world units and reports its bounds. Register it and it appears in the editor's Add menu and Inspector.

type Totem struct {
  Height float64
  Tint   ascdii.Color
}

func (t *Totem) Kind() string { return "totem" }
func (t *Totem) bind() *ascdii.Binder {
  return ascdii.Bind().Float("height", &t.Height, 1, 20).Color("tint", &t.Tint)
}
func (t *Totem) Props() []ascdii.Prop            { return t.bind().Props() }
func (t *Totem) Set(n string, v any) error     { return t.bind().Set(n, v) }
func (t *Totem) Bounds(tr ascdii.Transform) ascdii.AABB {
  return ascdii.Footprint(tr.Pos, ascdii.V3(1, 1, t.Height))
}
func (t *Totem) Draw(c *ascdii.Context, tr ascdii.Transform) {
  c.Box(t.Bounds(tr), ascdii.M(t.Tint))
  c.Shadow(tr.Pos, 1, .7, .6)
}

e.Registry().Node("totem", func() ascdii.Node { return &Totem{Height: 4, Tint: ascdii.Hex("#9a8a70")} })

The drawing context has boxes, prisms, cylinders, cones, gables, pyramids, blobs, terrain, sprites with bone transforms, particles, shadows and point lights. Depth and normals are always derived for you.

Content packs

To use your node kinds in the editor and in built games, ship them as a pack and add it where the editor and the ascdii player list their packs, next to the Dragonfall pack. Projects that need it name it in their manifest.

ascdii.Pack{Name: "mygame", Install: func(r *ascdii.Registry, lib *ascdii.Library) {
  r.Node("totem", func() ascdii.Node { return &Totem{Height: 4} })
}}
