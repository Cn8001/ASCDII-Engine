Go API

The engine is available to Go programs through one public package, gitlab.com/rapsodoinc/rapsodo-studios/ascii-engine/pkg/ascdii: scenes, components, the render pipeline and the game loop.

A minimal program

package main

import (
  "context"
  "os"

  "gitlab.com/rapsodoinc/rapsodo-studios/ascii-engine/pkg/ascdii"
)

func main() {
  e := ascdii.New(ascdii.Options{})
  s := e.Scene()
  s.Add("ground", ascdii.Ground(40, 40, ascdii.Hex("#46623e")))
  s.Add("crate", ascdii.Box(ascdii.V3(2, 2, 2), ascdii.Hex("#b08050"))).Blocking()
  hero := s.Add("hero", ascdii.Blob(.8, ascdii.Hex("#e8b04b"))).At(0, 5, 0).With(ascdii.Player(), ascdii.Quit("q"))
  hero.Add("camera", ascdii.CameraComponent(30))      // the camera rides with the hero
  s.Animate("crate", ascdii.Tween("pos.z", 0.0, 1.5, 1.2, ascdii.InOut).Bouncing())
  _ = e.Run(context.Background(), os.Stdin, os.Stdout)
}

A project folder is loaded instead of building the scene in code:

e, err := ascdii.OpenDir(ctx, "~/games/quest", ascdii.Options{})

Custom components

A component exposes its properties through a binder; to be drawn, it draws in world units and reports its bounds. Registered with a menu entry, it appears in the GameObject menu, in Add Component and in the Inspector. Further optional interfaces let a component tick, update in play mode, receive keys, block the player, collide, provide a camera view or offer methods to Lua.

type Totem struct {
  Height float64
  Tint   ascdii.Color
}

func (t *Totem) Kind() string { return "totem" }
func (t *Totem) bind() *ascdii.Binder {
  return ascdii.Bind().Float("height", &t.Height, 1, 20).Color("tint", &t.Tint)
}
func (t *Totem) Props() []ascdii.Prop            { return t.bind().Props() }
func (t *Totem) Set(n string, v any) error     { return t.bind().Set(n, v) }
func (t *Totem) Bounds(tr ascdii.Transform) ascdii.AABB {
  return ascdii.Footprint(tr.Pos, tr.Size(ascdii.V3(1, 1, t.Height)))
}
func (t *Totem) Draw(c *ascdii.Context, tr ascdii.Transform) {
  c.Box(t.Bounds(tr), ascdii.M(t.Tint))
  c.Shadow(tr.Pos, 1, .7, .6)
}

e.Registry().Register("totem", func() ascdii.Component { return &Totem{Height: 4, Tint: ascdii.Hex("#9a8a70")} },
  ascdii.ComponentMeta{Category: "3d", Label: "Totem", Object: true})

Object: true offers the kind in the GameObject menu as a ready object; kinds with false appear only in Add Component. The drawing context provides textured faces, boxes, prisms, cylinders, cones, gables, pyramids, blobs, terrain, sprites with bone transforms, particles, shadows and point lights; depth and normals are derived automatically.

Sprites whose art is finer than the dots they cover can be supersampled: s := c.Sprite(pos, scale, flip).Smooth(radius) before drawing and s.End() afterwards, where radius bounds the art around the anchor in art pixels. Sprites drawn at one dot per art pixel or larger are drawn directly.

Code modules

Components used in the editor and in built games are shipped as a module, added where the editor and the ascdii player list their modules, next to the Dragonfall module. Projects that use a module name it in their manifest, usually because a package that requires it was installed.

ascdii.Module{Name: "mygame", Install: func(r *ascdii.Registry, lib *ascdii.Library) {
  r.Register("totem", func() ascdii.Component { return &Totem{Height: 4} }, ascdii.ComponentMeta{Category: "mygame"})
}}
