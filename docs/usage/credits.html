Credits

The libraries ASCDII Engine is built with, and their licenses.

Ebitengine

The window display, which shows games in a desktop window, is built on Ebitengine by Hajime Hoshi and the Ebitengine contributors, released under the Apache License 2.0. Ebitengine opens the window, uploads the frame to the graphics card, scales it, draws the text of overlays and reports the keyboard. It is part of ascdii-player-window and of games built from it; the terminal programs do not include it. See Window output.
