Lua scripting

Game logic lives in Lua files in your project's scripts folder. Write them in your own code editor; the engine reloads a script the moment you save it.

Your first script

  1. Select an entity, press Add Component and choose New script. Name it door. The editor creates scripts/door.lua, attaches it and opens it in your code editor.
  2. Replace the file with the code below and save.
  3. Press play, walk close to the door and press E.
-- scripts/door.lua
function start(self)
  self.open = false
end

function key(self, k)
  if k == "e" then
    self.open = not self.open
    tween(self, "pos.z", self.open and 4 or 0, 0.6)
    return true
  end
end

function update(self, dt)
  local hero = find("hero")
  if hero and dist(self, hero) < 3 then
    say("press E", 0.3)
  end
end

self is the entity the script is attached to. Its methods come from the engine; any other field you set on it, like self.open, is your own state.

Hooks

HookWhen
start(self)Once, before the first update, and again after a reload.
update(self, dt)Every simulation step; dt is in seconds.
key(self, k)On a key press. Names are letters, space, enter, up, down, left, right. Return true to stop other behaviours from also handling it.

Entity methods

MethodDoes
e:get(prop)Read any Inspector property: "awake", "pos", "glow", "player.speed". Vectors come back as tables with x, y, z; colors as hex strings.
e:set(prop, value)Write a property, with the same names.
e:pos()Returns x, y, z.
e:moveTo(x, y, z), e:move(dx, dy, dz)Place or nudge. z is optional.
e:name()The entity name.
e:tween(prop, to, seconds, ease)Animate from the current value.
e:say(text, seconds)Show a floating label over the entity.
e:destroy()Remove the entity.

Global functions

FunctionDoes
find(name)The first entity with that name, or nil.
dist(a, b)Distance on the ground between two entities.
tween(e, prop, to, seconds, ease)Same as e:tween.
say(text, seconds)Floating label over the script's own entity. Calling it every frame with the same text just keeps it visible.
spawn(prefab, x, y, z)Instantiate a prefab, returns the new entity.
log(...)Write to the Console.
time()Scene time in seconds.
hour(), setHour(h)Read or set the time of day, 0 to 24.
quit()End the game.

The standard Lua math, string and table libraries are available. Scripts run in a sandbox: there is no file, network or OS access.

Errors and hot reload

A runtime error stops only that script and appears in the Console with the file and line, for example scripts/door.lua:12: attempt to index a nil value. Double click it to jump to the line. Fix the file, save, and the script reloads and runs start again.

Scripts and play modeScripts run in play mode and in built games. In the editor's Live preview they do not run, so editing never moves things by logic.
