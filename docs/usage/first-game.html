Start

Your first game

Fifteen minutes from nothing to a knight walking past a castle at sunset. You will create a project, look around, change things, play, save and commit.

1. Create a project

  1. Start the editor. After the splash you see the start screen.
  2. Pick Dragonfall as the template (the default, Empty, starts with nothing), type a name, choose a Location with the folder dialog and press Create. Later you can make more projects from the toolbar without closing the editor.
  3. The editor creates <location>/<name>/ with a .ascdiiproj manifest, scenes, prefabs, art and scripts, and opens it.

Prefer the terminal? The same thing:

ascdii new ~/games/quest -name "Quest" -template dragonfall

2. Look around

  • Drag with the left mouse button to pan, right drag to orbit, use the wheel to zoom.
  • Click anything to select it. The Inspector shows its components.
  • Press F to frame the selection.
  • The sun button in the view toolbar toggles Live: water, wind, flames and animation clips move while you edit. It is off when the editor opens, so nothing plays until you ask for it.

3. Change something

  1. Select dragon in the Hierarchy and switch awake on in the Inspector. It wakes, flaps and breathes fire in the editor.
  2. Select Scene at the top of the Hierarchy. Drag the hour label left and right: every label next to a number is a scrub handle. Watch the sun travel and the lanterns take over at night.
  3. Open the Project tab, drag the lantern prefab into the view and drop it on the road. It lands exactly under the cursor.
  4. Move it with the gizmo: the red arrow moves along X, the green along Y, the amber one changes height, the square in the middle moves freely on the ground.

4. Play

Press Space or the play button. The view switches to Game and uses the scene's own camera. Click the view and use WASD, Space to jump, E near the dragon, T for a sunset.

Press Esc to stop. The scene is exactly as it was before you pressed play.

5. Save and commit

Ctrl+S writes the scene. The project is ready for git: new projects come with a .gitignore that keeps the build/ folder out.

cd ~/games/quest
git init
git add .
git commit -m "First scene"

6. Ship it

Press Build, keep Windows and Linux checked, set the version and press Build again. Build and release explains what you get.
