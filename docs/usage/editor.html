The editor

A guided tour of every panel. The layout follows Unity on purpose, so most of it should feel familiar.

Toolbar

Left: the logo, the project name and version, buttons to open another project or close this one and return to the start screen, and the scene picker. The key next to it marks the open scene as the one a build starts with. Center: Play, Step (one frame while paused) and Stop. Right: undo, redo, save (a dot means unsaved changes) and Build.

Hierarchy

  • Every entity of the scene in a tree. Drag rows onto each other to parent them; drop on empty space to move to the root.
  • Double click a name to rename. The eye hides an entity and its children.
  • Right click for Add, Focus, Duplicate, Save prefab, Unpack and Delete.
  • Prefab instances show a package icon in amber; their inner entities are listed in italics and cannot be edited directly.
  • Select Scene at the top to edit the camera and the environment: time of day, sun, ambient light, sky and fog.

Scene and Game views

The Scene view has its own free camera, so looking around never changes your game. The Game view shows the scene camera, which is what players see. Align copies the Scene view into the game camera.

The view toolbar switches between dots (what a terminal shows) and pixels (the colors before Braille encoding), picks the cell size (smaller cells give more resolution) and toggles Live.

Inspector

Components are cards: Transform first, then the node (box, light, hero and so on), then behaviours. Behaviours have a checkbox to switch them off without losing their settings, and an X to remove them. Add Component searches behaviours and your Lua scripts, and can create a new script on the spot.

Number labels are scrub handles: drag them sideways, hold Shift for fine steps. The diamond at the end of a row records an animation key for that property.

Pipeline

The second tab on the right lists the render passes by stage with a toggle, live timings and their settings. Drag passes to reorder them inside their stage. Rendering covers what each one does.

Project, Console and Animation

  • Project: scenes, prefabs, art and scripts of the project folder. Double click opens a scene, places a prefab or sprite, or opens a script in your code editor. Create makes a script or a scene. Files you change outside the editor are picked up automatically.
  • Console: messages from scripts and the engine. Filter by level, see repeats collapsed with a count, double click a script error to jump to the line.
  • Animation: clips and keys of the selection. It can float as its own window. See Animation.
