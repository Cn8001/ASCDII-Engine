Guides

The editor

A guided tour of every panel. The layout follows Unity on purpose, so most of it should feel familiar.

Toolbar

Left: the logo, the project name and version, buttons for a new project (Ctrl+N, without leaving the editor), to open another project or to close this one and return to the start screen, the scene picker, and the Package Manager. The key next to it marks the open scene as the one a build starts with. GameObject opens the menu that creates objects, see GameObjects and components. Center: Play, Step (one frame while paused) and Stop. Right: undo, redo, save (a dot means unsaved changes) and Build.

Hierarchy

  • Every object of the scene in a tree. Drag rows onto each other to parent them; drop on empty space to move to the root.
  • Double click a name to rename. The eye hides an object and its children.
  • Right click for Create, Focus, Duplicate, Save prefab, Unpack and Delete. The + button opens the same Create menu.
  • Drag rows onto object slots in the Inspector to fill references, and Project tiles or files from your file manager onto rows to add models, prefabs and scripts or to apply a material.
  • Prefab instances show a package icon in amber; their inner objects are listed in italics.
  • Select Scene at the top to edit the camera and the environment: time of day, sun, ambient light, sky and fog.

Scene and Game views

The Scene view has its own free camera, so looking around never changes your game. The Game view shows the scene camera, which is what players see. Align copies the Scene view into the game camera.

In the Scene view an empty ground shows a grid with the X axis in red and the Y axis in green; it is an editor aid, listed as the grid pass in the Pipeline tab, and never appears in the Game view or in builds. The view always shows exactly what a terminal will show: the same Braille pattern and the same two colors in every cell. The toolbar only changes how those cells are drawn: dots draws the Braille dots with gaps, like a terminal font, and pixels draws the same dots without gaps, which is easier on the eyes but carries the same information. The toolbar also picks the cell size (smaller cells give more resolution) and toggles Live, which plays water, wind and animation clips while you edit; it starts off. The corner of the view shows the render and paint time of each frame.

Inspector

The header holds the name, visibility, tag and Solid. Below it come Transform and one card per component, each with a checkbox and a ⋮ menu for Reset, Move Up, Move Down and Remove. Add Component searches every component kind and your Lua scripts, and can create a new script on the spot. Slots for objects, components, prefabs, textures and materials take drops, as described in References. Clicking a texture, material or model in the Project window shows its settings here instead.

Number labels are scrub handles: drag them sideways, hold Shift for fine steps. The diamond at the end of a row records an animation key for that property.

Braille brush

For small fixes on a model or primitive without a 3D tool: select an object and turn on the brush in the view toolbar. Drag over the object to paint its dots in the chosen color, or switch to erase to hide them. The size slider sets the brush in world units. Strokes are stored in a Paint component in the object's own space, so they move, turn and scale with it, and the model file never changes; remove the component to undo all of it, or use undo for single strokes.

Pipeline

The second tab on the right lists the render passes by stage with a toggle, live timings and their settings. Drag passes to reorder them inside their stage. Rendering covers what each one does.

Project, Console and Animation

  • Project: the project folder with its folders. Double click opens a scene, places a prefab, model or sprite, or opens a script in your code editor. Drop files from your file manager to import them. See Assets and import.
  • Console: messages from scripts and the engine. Filter by level, see repeats collapsed with a count, double click a script error to jump to the line.
  • Animation: clips and keys of the selection. It can float as its own window. See Animation.
  • Animator: the state graph of an animator controller, in a window of its own. See Animator.
  • Packages: the package manager, from the package button in the toolbar. See Packages.
