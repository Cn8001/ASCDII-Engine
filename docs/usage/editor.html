Guides

The editor

A reference for every part of the editor window. The editor is started by ascdii; see Install.

Window title

The title shows the open scene, the project and the engine version, for example dragonfall.scene.json - Dragonfall - ASCDII Engine 0.0.1. A leading * indicates that the scene has unsaved changes; it disappears when the scene is saved.

Toolbar

AreaControls
LeftProject name and version; New project (Ctrl+N), Open project and Close project; the scene picker; the key, which marks the open scene as the start scene of builds; the Package Manager; the GameObject menu, see GameObjects and components.
CenterPlay or pause (Space), Step, which advances one frame while paused, and Stop (Esc).
RightUndo, redo, save (a dot indicates unsaved changes) and Build (Ctrl+B), see Build.

Hierarchy

  • Lists every object of the scene as a tree. Dragging a row onto another row makes it a child; dropping it on Scene moves it to the top level. The object keeps its place in the world, see Parents and children.
  • A double click renames an object. The eye icon hides an object and its children.
  • The context menu provides Create, Focus, Duplicate, Save as Prefab, Unpack and Delete. The + button opens the Create menu.
  • Rows can be dragged onto object slots in the Inspector to fill references. Project tiles and files from the file manager can be dropped onto rows to add models, prefabs and scripts, or to apply a material.
  • Prefab instances are marked with an amber package icon; their inner objects are listed in italics.
  • Selecting Scene at the top shows the environment in the Inspector: time of day, sun, ambient light, sky and fog.

Scene and Game views

The Scene view has an editor camera of its own; navigating it never changes the game. The Game view shows the game camera, which is what players see. Align moves the camera object to the current Scene view, and creates a Main Camera first in a scene without one. A scene without a camera shows No camera in the Game view.

View toolbar

The toolbar in the top left corner of the view, from left to right:

ControlFunction
Move, Rotate, ScaleThe transform tool for the selected object, also on W, E and R. Move drags the red (X), green (Y) or amber (height) arrow, or the square in the middle along the ground. Rotate drags the amber ring around the up axis, or the red and green handles to tilt. Scale drags a handle to stretch one axis, or the square to scale evenly. Each drag is one undo step.
Braille dots, PixelsHow cells are drawn on screen. Braille dots draws every Braille dot as a separate square with gaps between them, as a terminal font does; this is the most accurate preview of a terminal. Pixels draws the same dots without gaps, which is easier to read at small cell sizes. Both modes show identical information: the same dots and the same two colors per cell that a terminal receives.
6, 8, 10, 12The cell width in screen pixels; a cell is twice as tall as it is wide. Smaller cells fit more columns into the view, so the scene is rendered with more detail. At the default window size, 6 shows about 155 columns, close to the 160 columns a game is designed for; larger sizes show fewer columns and coarser detail, as a terminal with a larger font would.
LiveRuns water, wind, particles and animation clips while editing. Scripts do not run in Live mode. Off by default.
GizmosShows or hides the collider outlines, collider handles and the camera frame described below. On by default.
Braille brushPaints or erases dots on the selected object, see Braille brush.

The corner of the view shows the grid size in cells, the render time and paint time of each frame, and the frame rate.

Gizmos

Gizmos are drawn only in the Scene view and never appear in the Game view or in builds.

  • Grid. Empty ground shows a grid with the X axis in red and the Y axis in green, listed as the grid pass in the Pipeline tab.
  • Colliders. Every collider in the scene is outlined at its bottom and top: green for solid colliders and blue for triggers, bright on the selected object and dimmed elsewhere.
  • Collider handles. The colliders of the selected object have square handles. On a box collider, the handles on each side change the size along that axis while the opposite side stays in place, and the handle on top changes the height. On a circle collider, the side handle sets the radius and the top handle the height. Exact values remain editable in the Inspector. See Physics.
  • Camera frame. The area of the ground the game camera shows is outlined in amber, bright when the camera object is selected.

Inspector

The header contains the name, visibility, tag and Solid. Below it follow Transform and one card per component, each with a checkbox to disable it and a ⋮ menu with Reset, Move Up, Move Down and Remove Component. Add Component searches all component kinds and the project's Lua scripts, and can create a new script. Slots for objects, components, prefabs, textures and materials accept drops, see References. Selecting a texture, material or model in the Project window shows its settings in the Inspector instead.

Labels of numeric fields are scrub handles: dragging sideways changes the value, and holding Shift makes the steps finer. The diamond at the end of a row records an animation key for that property.

Braille brush

The brush makes small corrections to a model or primitive without an external 3D tool. Select an object, enable the brush in the view toolbar, then drag over the object to paint its dots in the chosen color, or enable erase to hide them. The size slider sets the brush radius in world units. Strokes are stored in a Paint component in the object's local space, so they move, rotate and scale with the object; the model file is not changed. Removing the component reverts all strokes; undo reverts single strokes.

Pipeline

The second tab on the right lists the render passes by stage, each with a toggle, its timing and its settings. Passes can be reordered within their stage by dragging. Rendering describes each pass.

Panels and windows

  • Project: the project folder. A double click opens a scene, places a prefab, model or sprite, or opens a script in the code editor. Files dropped from the file manager are imported into the open folder. See Assets and import.
  • Console: messages from scripts and the engine, with a filter by level and repeated messages collapsed into a count. A double click on a script error opens the script at that line.
  • Animation: the clips and keys of the selection; it can be detached into a floating window. See Animation.
  • Animator: the state graph of an animator controller, in a floating window. See Animator.
  • Particle Editor: presets, a preview and all settings of the selected particle system, opened from the sparkle button on its card. See Particles.
  • Package Manager: installs and removes packages. See Packages.
