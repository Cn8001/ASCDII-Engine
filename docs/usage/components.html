Reference

Component reference

Every built in component kind with all of its properties. Property names are used in the Inspector, in animation tracks, in prefab overrides and from Lua as <kind>.<property>, for example light.radius; see Property names.

Types: float and int are numbers, with the range the Inspector allows; vec3 is three numbers x, y, z; color is a hex color; enum is one of the listed words; object, material, model, asset, audio, controller and script are references, see References. Components of code modules are documented with the module, such as the Dragonfall module.

Camera

Camera camera

Makes its object the game camera. The object's position is the point the camera looks at and its rotation around Z turns the view; as a child of another object the camera moves with it. The first enabled camera on a visible object is used; a scene without one shows No camera. GameObject menu and Add Component.

PropertyTypeDefaultDescription
spanfloat, 4 to 40036World units across the width of the view; smaller values zoom in.
pitchfloat, 15 to 8955Angle above the ground in degrees; 90 looks straight down.
anchorXfloat, 0 to 10.5Horizontal screen position of the target, 0 left to 1 right.
anchorYfloat, 0 to 10.6Vertical screen position of the target, 0 top to 1 bottom.
