CLI reference

The ascdii binary is both the developer tool and the game player. When it finds a packed project inside itself, it just plays it.

Main menu

Start ascdii without arguments, or double click it, and a menu opens in the terminal: continue the last project, play the Dragonfall demo, open a project from the recent list or by path, or create a new one. Use the arrow keys or W S, Enter to choose, Esc to go back. When a game ends you return to the menu. The recent list is shared with the editor.

Commands

CommandDoes
ascdii new <dir> [-name N] [-template dragonfall]Create a project. Without a template it starts empty.
ascdii pack list <dir>Installed packages, and built in ones that are not.
ascdii pack install <dir> <file | name>Install a .ascdiipack or a built in package such as dragonfall.
ascdii pack remove <dir> <name>Remove a package, and the modules only it needed.
ascdii pack export <folder> -name N [-version V] [-description D] [-out file]Write a folder, .meta files included, as a .ascdiipack.
launcherThe terminal main menu as its own program; ascdii without arguments shows the same.
ascdii run <dir>Play a project folder in this terminal.
ascdii preview <dir> [-size 160x50] [-time 2] [-hour 22] [-plain]Print one frame after simulating some time.
ascdii build <dir> [-out path] [-player path]One executable. The player defaults to this binary.
ascdii release <dir> [-version v] [-players dir]Executables, zips and SHA256SUMS for every available player.
ascdii versionPrint the engine version.
ascdii helpPrint this list.
