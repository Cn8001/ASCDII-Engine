Reference

CLI reference

ascdii is the launcher, the command line tool and the game player. A copy that contains game data, as in a build, plays that game.

Launcher

ascdii without arguments opens the launcher in the terminal. It lists the recent projects, followed by Open project, which accepts a folder or a .ascdiiproj path, and New project, which asks for a name, a location and a template. The selected project opens in the editor, and the launcher remains open for further projects. The arrow keys or W and S move the selection, Enter selects and Esc goes back. The editor uses the same list of recent projects and is always started from the launcher; started directly, it opens the launcher in a new terminal window.

Commands

CommandFunction
ascdii new <dir> [-name N] [-template dragonfall]Creates a project. Without a template, the project contains a manifest and a start scene with a camera.
ascdii run <dir>Plays a project folder in the terminal.
ascdii preview <dir> [-size 160x50] [-time 2] [-hour 22] [-plain]Prints one frame after simulating -time seconds, at an optional time of day; -plain omits colors.
ascdii build <dir> [-out path] [-player path] [-single]Builds a game folder with the player, data/game.pak and SHA256SUMS; -single builds one executable. The player defaults to this ascdii. See Build.
ascdii pack list <dir>Lists installed packages and the built in packages that are not installed.
ascdii pack install <dir> <file | name>Installs a .ascdiipack file or a built in package such as dragonfall.
ascdii pack remove <dir> <name>Removes a package and the modules only it required.
ascdii pack export <folder> -name N [-version V] [-description D] [-out file]Writes a folder, with its .meta files, as a .ascdiipack. See Packages.
ascdii versionPrints the engine version.
ascdii helpPrints the list of commands.

A built game accepts --preview [-size 160x50] [-time 2] to print one frame instead of starting.

Make targets

For working on the engine from source; see Building from source.

TargetFunction
make testgo vet and go test -race for the whole module.
make cliBuilds bin/ascdii.
make playersBuilds the Linux and Windows players into bin/, next to the editor, for builds on both platforms.
make editor-linux, make editor-windowsBuilds the editor and copies it into bin/, next to ascdii.
make editor-devRuns the editor with hot reload, without the launcher.
make distBuilds the release archives in bin/dist.
make hello, make dragonfallRuns the two examples in the terminal.
make templateRegenerates the Dragonfall template from its Go source.
make brandRegenerates the application icon.
make benchMeasures the frame time of the sample scene.

The documentation has two maintenance tools: python3 docs/nav.py rewrites the navigation of every page, and go run ./cmd/docref docs/usage/components.html regenerates the component reference (with docs/usage/dragonfall.html dragonfall for the module).
