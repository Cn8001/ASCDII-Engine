Models

Wavefront .obj models from Blender or other 3D tools are drawn in Braille with lighting, shadows and fog, at any rotation.

Importing

  1. Export the model as .obj, with its materials as .mtl if it has any.
  2. Drag the .obj into the Scene view. It is copied into the open folder together with its .mtl files and the textures they name, keeping their relative paths, and placed where it was dropped.
  3. Further instances are created from GameObject, Model, by dragging the model tile from the Project window, or by a double click on it.

What is read

OBJ / MTLUsed for
v, fPositions and faces; faces with more than three corners are split into triangles.
vtTexture coordinates.
usemtl, mtllibWhich material each part uses.
KdThe part's color.
map_KdThe part's texture, imported as a texture asset.

Normals in the file are ignored; faces are shaded flat, which reads best at Braille resolution. A few hundred faces are sufficient for a building.

Import settings

Selecting a model tile shows its import settings in the Inspector:

SettingMeaning
upZOff for the common Y up export; on for files that are already Z up, as some CAD tools write them.
scaleWorld units per file unit. One world unit is one tile of ground; a door is about 2 units tall.

The model is turned so that its front, as seen in the 3D tool's front view, faces the default camera.

The Mesh component

PropertyMeaning
modelThe model asset.
materialOptional; replaces the model's own materials on every part.
tint, emissiveColor multiplied over the model, and self lighting.
twoSidedDraws back faces as well, for open models or models with inconsistent face directions.
shadowA soft contact shadow on the ground.

The object's rotation, scale and flip apply to the model. A solid object blocks with its rotated bounds; a Mesh Collider blocks with the model's outline seen from above, see Physics.
