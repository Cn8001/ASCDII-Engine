Install

ASCDII Engine consists of two programs: ascdii, the launcher and command line tool, and ascdii-editor, the desktop editor. The editor is always started from ascdii.

Installation

PlatformArchiveContents
Windowsascdii-0.0.1-windows-amd64.zipascdii.exe, ascdii-editor.exe, and ascdii-linux-amd64 for building Linux games
Linuxascdii-0.0.1-linux-amd64.tar.gzascdii, ascdii-editor, and ascdii-windows-amd64.exe for building Windows games
  1. Extract the archive for the platform into any folder, for example C:\Tools\ascdii or ~/tools/ascdii. The files must remain in the same folder.
  2. Optionally, add that folder to PATH to run ascdii from any location.

Starting the engine

  1. Run ascdii. The launcher opens in the terminal and lists recent projects.
  2. Select a recent project, Open project or New project. The selected project opens in the editor; the launcher remains available for further projects.

Starting ascdii-editor directly opens the launcher instead.

Terminal requirements

Games and the launcher require a terminal with 24 bit color and a font that includes the Braille block (U+2800 to U+28FF). Supported terminals include Windows Terminal, WezTerm, Kitty, Alacritty, GNOME Terminal, iTerm2 and the Visual Studio Code terminal. A window of at least 120 by 40 cells is recommended.

ascdii version
ascdii run ~/games/demo
Windows consoleThe legacy Windows console host does not support 24 bit color. Use Windows Terminal.
Distributing gamesBuilt games run on their own and require only a terminal. See Build.

Building from source

Required only for development of the engine and the editor. All programs build from one Go module.

ToolVersionPurpose
Go1.24 or newerEngine, CLI, editor backend
Node.js20 or newerEditor interface (Vue, Vite, Tailwind)
Wails CLIv2.17go install github.com/wailsapp/wails/v2/cmd/wails@v2.17.0
WebKitGTK 4.1 headersLinux and WSL onlysudo apt install libwebkit2gtk-4.1-dev
make test             # vet and tests for the whole module
make cli              # ascdii
make players          # ascdii for every platform, so builds can target all of them
make editor-linux     # ascdii-editor for Linux
make editor-windows   # ascdii-editor for Windows
make dist             # the archives listed under Installation, in bin/dist

All programs are written to bin/; bin/ascdii starts the launcher, which finds the editor next to it. Windows programs are cross compiled from Linux and WSL without additional toolchains. make editor-dev starts the editor with hot reload and without the launcher, and serves it at http://localhost:34115 for browser developer tools.
