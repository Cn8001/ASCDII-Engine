Install

Most people only need the two programs: the editor, ascdii-editor, and the command ascdii, which also plays games. Building from source is only for working on the engine itself.

Download and run

Get the archive for your platform from your team's release page; it holds both programs:

PlatformArchiveContains
Windows 10 and 11ascdii-0.0.1-windows-amd64.zipascdii-editor.exe, ascdii.exe
Linux, WSLascdii-0.0.1-linux-amd64.tar.gzascdii-editor, ascdii
  1. Unpack it anywhere, for example into C:\Tools\ascdii or ~/tools/ascdii.
  2. Start ascdii-editor. The start screen creates a project or opens one; nothing else is needed for the editor.
  3. To use ascdii from any folder, add the unpacked folder to your PATH. Run ascdii on its own for the terminal main menu, or ascdii help for the commands.
NeedsWindowsLinux
Editor windowWebView2, already part of Windows 10 and 11WebKitGTK 4.1: sudo apt install libwebkit2gtk-4.1-0
Sound in gamesnothingALSA, installed on almost every desktop (libasound2)
Players need nothingGames you build are folders with one executable and a data folder. The people who play them only need a terminal, see below.

Check your terminal

Games run in any terminal with 24 bit color and a font that has the Braille block (U+2800 to U+28FF): Windows Terminal, WezTerm, Kitty, Alacritty, GNOME Terminal, iTerm2 and the VS Code terminal all work. A window of about 120 by 40 cells or larger looks best; a smaller font gives more detail.

ascdii version
ascdii new ~/games/demo -template dragonfall
ascdii run ~/games/demo
Not the old Windows consoleOn Windows use Windows Terminal, not the legacy console host, which has no 24 bit color.

Build from source

For changing the engine or the editor. Everything builds from one Go module.

ToolVersionUsed for
Go1.24 or newerEngine, CLI, editor backend
Node.js20 or newerEditor interface (Vue, Vite, Tailwind)
Wails CLIv2.17go install github.com/wailsapp/wails/v2/cmd/wails@v2.17.0
WebKitGTK 4.1 headersLinux and WSL onlysudo apt install libwebkit2gtk-4.1-dev
# tests and vet for the whole module
make test
# the ascdii command and game player
make cli
# player binaries the editor builds games from; run before any editor build
make players
# the editor, for this machine and for Windows
make editor-linux
make editor-windows
# the archives from Download and run, in bin/dist
make dist

The editor lands in cmd/editor/build/bin/. From WSL the Windows programs are cross compiled; no extra toolchain is needed. make editor-dev starts the editor with hot reload, also reachable from a browser at http://localhost:34115 for the developer tools.
