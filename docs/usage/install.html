Install

The engine and editor build from one Go module. You need Go, Node and the Wails CLI. Everything else is vendored or generated.

Requirements

ToolVersionUsed for
Go1.24 or newerEngine, CLI, editor backend
Node.js20 or newerEditor interface (Vue, Vite, Tailwind)
Wails CLIv2.17Desktop editor builds: go install github.com/wailsapp/wails/v2/cmd/wails@v2.17.0
WebKitGTK 4.1Linux and WSL onlyThe editor window: sudo apt install libwebkit2gtk-4.1-dev
WindowsGames and the editor run natively on Windows. You can also build both from WSL: the Windows executables are cross compiled, no extra toolchain needed.

Build everything

# tests and vet for the whole module
make test

# the ascdii CLI and game player
make cli

# player binaries the editor uses to build games
make players

# the editor, for this machine and for Windows
make editor-linux
make editor-windows

The editor lands in cmd/editor/build/bin/. Run ascdii-editor on Linux or WSL, or ascdii-editor.exe on Windows.

Always run make players firstThe editor embeds the player binaries it appends your game to. Without them the Build window shows the platforms as unavailable.

Develop the editor

make editor-dev

This starts the editor with hot reload for the interface. The same session is also reachable from a browser at http://localhost:34115, which is handy for the developer tools.

Check your terminal

Games need a terminal with truecolor and a font that has the Braille block (U+2800 to U+28FF). Windows Terminal, WezTerm, Kitty, Alacritty and the VS Code terminal all work. A window of about 120x40 cells or larger looks best.

ascdii version
ascdii new ~/games/demo -template dragonfall
ascdii run ~/games/demo
