Reference

Lua API

Every function and field available to scripts. Names are lower case with underscores. Positions, rotations and sizes are vec3 values in world units and degrees; colors are hex strings such as "#ff8800".

Finding objects

FunctionReturns
find(name)The first object with that name, or nil.
find_all(name)Every object with that name, as a list.
find_by_tag(tag)Every object with that tag.
find_by_component(kind)Every object that has a component of that kind, such as "light".
find_by_prefab(prefab)Every instance of a prefab, given as a path such as "prefabs/lantern.prefab.json" or a prefab() field.

Creating and removing

FunctionDoes
create(name, parent)A new empty object; parent is optional.
spawn(prefab, pos, parent)An instance of a prefab at pos (a vec3, or x, y, z) in the world; with parent it becomes that object's child.
destroy(obj)Removes an object and its children, after their on_destroy hooks.

Transform

World values include all parents; local values are relative to the parent, as the Inspector shows them. For objects at the top level both are equal.

FieldRead / writeMeaning
position, local_positionbothPosition in the world, or relative to the parent.
rotation, local_rotationbothDegrees around X, Y and Z, in the world or relative to the parent.
scale, local_scalebothScale relative to the parent; both names mean the same.
world_scalereadScale after all parents.
forward, right, upreadThe object's X, Y and Z directions in the world, after rotation.
MethodDoes
o:set_parent(p, keep_world)Makes the object a child of p, or moves it to the top level when p is nil. keep_world defaults to true; with false the local values are kept, so the object moves with its new parent.
o:translate(v, space)Moves along the object's own axes, or along the world axes with "world".
o:rotate(degrees)Adds a vec3 of degrees to the local rotation.
o:look_at(target)Turns around Z to face an object or a vec3 on the ground plane.
o:transform_point(p), o:inverse_transform_point(p)A point from the object's space to the world, and back.
o:move(delta), o:move_to(pos)Moves by a world offset, or to a world position; a vec3 or x, y, z.
function update(self, dt)
  self:rotate(vec3(0, 0, 90 * dt))            -- spin a quarter turn a second
  self:translate(vec3(2 * dt, 0, 0))          -- walk forward, wherever it faces
end

function key(self, k)
  if k == "e" then
    find("sword"):set_parent(self)         -- pick it up; it stays where it was
  end
end

Components

Input and time

FunctionReturns
key_down(k)Whether a key is held: "w", "space", "up", "enter".
key_pressed(k)Whether a key went down this frame.
time()Scene time in seconds.
time_scale(k)Sets the game speed when given a number (0 pauses, 0.5 is slow motion) and returns it.
log(...)Writes to the Console, tagged with the script's file.
say(text, seconds)A label over the script's own object; say(obj, text, seconds) over another.
tween(obj, prop, to, seconds, ease)Same as obj:tween.
play_sound(sound, volume)Plays a sound asset once, by path or from a field.
quit()Ends the game.

Key releases are exact in the editor and in terminals that report them: Windows Terminal (win32 input mode) and terminals with the kitty keyboard protocol, such as kitty, WezTerm and foot. The game enables both when it starts, so several keys can be held at once, for example W and D to move diagonally. Other terminals report only presses; there a key counts as held for a short time after each press, extended by key repeat, and only the most recently pressed key repeats.

Camera

The global camera controls the game camera, the scene's camera object. In a scene without a camera its fields read as nil and setting them raises an error. See Cameras.

Field or functionMeaning
camera.targetThe point the camera looks at; on a camera object, its world position.
camera.spanWorld units across the width of the view.
camera.pitch, camera.yawAngle above the ground, and rotation around the up axis, in degrees.
camera.anchorX, camera.anchorYScreen position of the target, 0 to 1.
camera.objectThe camera's GameObject, or nil in a scene without a camera.
camera.follow(obj, rate)Moves the camera toward obj every frame; camera.follow(nil) stops.
camera.span = 24
camera.pitch, camera.yaw = 45, 15
camera.target = vec3(10, 20, 0)
camera.follow(find("hero"), 5)
camera.object:set_parent(find("cart"))   -- ride along with the cart

Drawing from Lua

A script with a draw(self, d) hook draws additional shapes every frame. Positions and sizes are in the object's local space, so the shapes move, rotate and scale with the object.

CallDraws
d:box(pos, size, color, glow)A box standing on pos.
d:blob(pos, radius, color, glow)A sphere resting on pos.
d:cylinder(pos, radius, height, color), d:cone(...)Upright solids.
d:point(pos, size, color, glow)A glowing dot, for sparks and stars.
d:light(pos, radius, color, intensity)A point light.
d:shadow(pos, rx, ry)A soft contact shadow.
function draw(self, d)
  local h = 1 + math.sin(time() * 3) * 0.3
  d:blob(vec3(0, 0, h), 0.4, "#9fd8ff", 0.8)
  d:light(vec3(0, 0, h), 6, "#9fd8ff", 1.2)
end

Earlier names

The functions of the first API remain available: dist(a, b) (distance on the ground), hour(), setHour(h), o:pos() and o:moveTo(x, y, z). position and rotation now hold world values; scripts that set them on child objects and expect local values use local_position and local_rotation.
